# Offline Smart Keyboard v0.4 — ЙЦУКЕН + скрытый T9 + контекст

## Что изменилось

Экранная раскладка осталась **обычной ЙЦУКЕН**. Блоки 2–9 работают **только внутри поискового движка**: слово переводится в цифровые группы, по локальному индексу находятся близкие кандидаты, затем выбирается вариант с минимальной буквенной ошибкой и лучшим контекстом.

В сравнении с v0.3:
- Демонстрационный словарь расширен до **508 уникальных словоформ** (это ещё НЕ полноценный русский словарь).
- Добавлен `ContextRanker`, учитывающий **предыдущее слово**, с небольшим явным списком сочетаний из `ru_bigrams.txt`. Эти сочетания составлены для демонстрации, а **не обучены** на пользовательских сообщениях.
- Добавлен поиск кандидатов, если во введённом слове **пропущена буква**, и проверка переставленных соседних букв.
- Неизменённые правильные словарные слова защищены от замены, даже если контекст предлагает другое слово.
- Контекст хранится **только в памяти**, обнуляется при переходе в другое поле. Сеть не используется и разрешение `INTERNET` отсутствует.
- Добавлены отдельные JVM-тесты контекста, синтетический нагрузочный тест и **скрипт импорта большого внешнего словаря** для будущих версий.

## Как работает

Например, `прывет` -> `привет`, `сиводня` -> `сегодня`, `сможеш` -> `сможешь`.

Неоднозначный пример с искусственным словарём: `вирю` имеет два похожих варианта — `верю` и `варю`. После `я` выбирается `верю`, после `суп` — `варю`. Без контекста система не должна делать уверенную автозамену. Правильно написанное слово `верю` не заменяется на `варю` ни при каком контексте.

Обрати внимание: **пунктуация, грамматика целого предложения и полноценное понимание смысла пока не реализованы**. Из трёх произвольных букв нельзя достоверно восстановить длинное предложение.

## Открыть в Android Studio

1. Распаковать ZIP и открыть каталог `OfflineSmartKeyboard_0_4` через **File → Open**.
2. Установить Android SDK 35, JDK 17+, Gradle 8.11.1. Проект использует Android Gradle Plugin 8.9.2 и Kotlin 2.2.20.
3. Если Android Studio потребует Gradle wrapper, сгенерировать его установленным Gradle (`gradle wrapper --gradle-version 8.11.1`). **Wrapper JAR и готовый APK в архив не включены**.
4. Установить приложение и нажать «Включить клавиатуру» в системных настройках, затем «Выбрать клавиатуру».
5. Набрать текст на обычной ЙЦУКЕН-раскладке. Индекс цифровых блоков на экране НЕ показывается.

**Важно:** Android SDK/Gradle недоступны в среде сборки архива; успешное создание APK и скорость на телефоне пока **не проверены**. Словарный модуль тестировался отдельно на настольной JVM.

## Проверки (на компьютере с Kotlin CLI / JDK)

```bash
bash scripts/test-blocks.sh   # базовые исправления и скрытые блоки
bash scripts/test-context.sh  # 14 контекстных и защитных проверок
bash scripts/bench-index.sh 10000  # синтетические слова, не реальный русский словарь
```

Для текущего теста с 10 000 **синтетических** слов на настольной JVM были получены: сборка индекса около 157 мс, p50 ~14 мкс, p95 ~29 мкс, p99 ~74 мкс для поиска. Это только пример одного прогона, не гарантированная производительность и **не время реакции клавиатуры Android**. Качество словаря на синтетике оценить невозможно.

## Подключение большого русского словаря (отдельный этап)

В архиве есть инструмент `scripts/import-leeds-words.py`. Он может превратить скачанный **на компьютере разработчика** список 50 000 русских слов в локальный словарь приложения (по умолчанию импортирует первые 15 000 и объединяет их с текущими формами):

```bash
python scripts/import-leeds-words.py ~/Downloads/50000-russian-words-cyrillic-only.txt --limit 15000
```

Источники: [список hingston/russian](https://github.com/hingston/russian/blob/master/50000-russian-words-cyrillic-only.txt), [условия CC BY 2.5](https://github.com/hingston/russian/blob/master/LICENSE.md). Данные основаны на частотном корпусе University of Leeds, редактирование/очистка — hingston. При распространении полученного словаря соблюдайте условия атрибуции. Скрипт полностью офлайн: исходный файл требуется предварительно скачать самостоятельно.

**Этот большой словарь НЕ включён в релиз v0.4.** До его реального подключения необходимо оценить расход памяти при загрузке, качество словоформ, покрытие разговорной речи и частоту ошибочных автозамен. Частоты в импортёре вычисляются приблизительно из рангов; это не истинные корпусные частоты.

## Ограничения и безопасность

- IME в текущей версии пока экспериментальный. Проверять на основном телефоне стоит осторожно, особенно для сообщений, финансовых форм, имён и адресов.
- Контекст — лишь предыдущее введённое слово, не содержимое чужих сообщений. Доступ к перепискам мессенджеров не предполагается.
- В полях паролей и полях, запрещающих подсказки/обучение, автокоррекция отключается. В конфигурации приложения **нет разрешения на интернет**.
- Автозамена допускается только при высокой уверенности; одна клавиша Backspace может вернуть исправленное слово в стандартном сценарии «слово + пробел».
- Если текст вводится в приложении, которое не поддерживает composing spans, поведение нужно тестировать отдельно. Используются `InputConnection.setComposingText` и `commitText`.
- **20 мс — инженерная цель для быстрого контура, а не измеренная характеристика.** Нужны Android-тесты p95/p99 (от нажатия до видимого результата), память и батарея.
- Пунктуация, морфология, учёт нескольких соседних слов, работа в иных языках и локальный смысловой ИИ — следующие этапы.

## Основные файлы

- `core/BlockSearchCorrector.kt`: поиск по буквам и невидимым цифровым блокам.
- `core/ContextRanker.kt`: локальные контекстные подсказки.
- `ime/OfflineKeyboardService.kt`: системная клавиатура Android с ЙЦУКЕН-раскладкой.
- `assets/ru_words.txt`: 508 демонстрационных словоформ.
- `assets/ru_bigrams.txt`: демонстрационные сочетания слов.
- `scripts/import-leeds-words.py`: воспроизводимый импорт внешнего словаря.
- `jvm-tests/`: тесты и микробенчмарк.
