# RussianKeyboard Android — контекстная проверка (v1.0.0-rc3)

В rc3 добавлены общий поиск новых опечаток, контекстное ранжирование,
продолжение слов, подсказки следующего слова, морфологическая защита
правильных словоформ и «Проверить фразу» с просмотром перед применением.
Доступны EN, цифры/символы и настройки. Подробности и ограничения:
[CONTEXT_KEYBOARD_RC3_RU.md](../docs/CONTEXT_KEYBOARD_RC3_RU.md).

Это **настоящая Android IME**, добавленная в тот же репозиторий, что и Python Trainer.
Офлайн-словарь: 100 000 словоформ и 1 000 000 индексированных синтетических
опечаток. Базовые 10 проверенных замен и демонстрационные правила запятых сохранены.

## Сборка

JDK 17, Android SDK 35, Gradle 8.9.

GitHub проверяет через четыре workflow: `validate` (Python и FP32/INT8 ONNX), `android-build` (unit/lint/APK и компиляция instrumentation), `android-emulator` (реальный ввод, Undo, API 35, 3 ГБ RAM) и `android-onnx-smoke` (INT8 inference и P50/P95/PSS на эмуляторе). См. `docs/GITHUB_TEST_MATRIX_RU.md`.

В проект добавлен экспериментальный Android ONNX Runtime через `OnDeviceRanker`. В обычный APK модель не включается и не вызывается из IME. Отдельный GitHub workflow `android-onnx-smoke` проверяет пакетирование синтетической ONNX-модели и инференс на эмуляторе. См. `docs/ONNX_ANDROID_INTEGRATION_RU.md`.

```sh
gradle -p android --no-daemon testDebugUnitTest assembleDebug
```

После успешного GitHub Actions `android-build` debug APK доступен в Artifacts.
CI требует проверку всех 1 000 000 пар через настоящий Kotlin-поиск и
100 000 разных целевых слов. Прежние регрессии, развёрнутые из 585 базовых
примеров, сохранены, но их количество больше не служит критерием покрытия
словаря. Проверяются также хеши и возможность mmap словаря внутри APK.
Путь сборки: `android/app/build/outputs/apk/debug/`. В GitHub Artifacts лежат отдельные APK: `app-arm64-v8a-debug.apk` (большинство современных ARM64), `app-armeabi-v7a-debug.apk` (старые 32-bit ARM) и `app-x86_64-debug.apk` (эмулятор). Выбирай APK под архитектуру телефона.

## Использование

Установи APK, открой приложение и нажми «Включить клавиатуру», затем «Выбрать клавиатуру».
Для тестов используй обычное поле ввода. Клавиатура распознаёт нажатия букв, Backspace,
пробел, запятую, точку и Enter. При пробеле пробует локальное исправление.
Над клавишами появляется вариант исправления. Нажатие на вариант применяет
его с пробелом; «Оставить» сохраняет набранное слово и добавляет пробел.
«Проверить фразу» предлагает исправление последних 240 символов, включая
простое согласование с явно указанным «он/она/оно» и ограниченные запятые.
Результат можно прокрутить целиком, применить или отменить. Backspace
отменяет всю замену фразы. Автозамену и подсказки можно выключить в ⚙.
Автоматически исправляются только частотные кандидаты с одной ошибкой,
для которых не найдено конкурирующего известного слова в модели одиночного
промаха. Редкие формы, неоднозначные варианты и две ошибки требуют выбора.

## Важно

- Нет INTERNET-разрешения, нет отправки текста и аналитики.
- В парольных и других чувствительных полях корректировки не запускаются. Также исключены поля имён, почтовых адресов, фонетического ввода и фильтров — движок не читает их содержимое для автокоррекции.
- Исправления букв и пунктуации пока детерминированные, не обученная нейросеть.
- Автозамена ограничена началом отдельного слова (в том числе после пробела или открывающей кавычки). Внутри адресов, URL, @упоминаний, #хештегов, путей, идентификаторов и слов через дефис она отключается, чтобы минимизировать ложные исправления.
- Слова с нестандартным чередованием прописных/строчных букв (никнеймы, стилизованный текст) не автокорректируются; обычная строчная, начальная заглавная и верхний регистр сохраняются.
- Не реализованы длинная история исправлений, разрешение местоимений,
  адаптация к собеседнику, все языки и пунктуация RUPunct. Одноразовый Undo уже
  работает; ONNX Runtime подключён экспериментально, но веса не включены в обычный APK.
- Нужны испытания на физических телефонах с 3–4 ГБ RAM: PSS, jank, температура и батарея. Синтетический эмуляторный benchmark не заменяет эти измерения.
- Не использовать прототип как основную клавиатуру для важных сообщений.

**Undo:** немедленный Backspace после автоматической или выбранной коррекции
возвращает исходное слово при совпадении текста. Следующий пробел оставляет
восстановленное слово без повторной автозамены. Ввод новой буквы сбрасывает
это одноразовое исключение. Следующие нажатия сбрасывают возможность отмены.

## Установка кандидата на реальный Android (без production-подписи)

Артефакт `russian-keyboard-debug-apk` в успешном GitHub Actions `android-build`
содержит **устанавливаемые debug-signed APK**, разделённые по ABI,
и файл `SHA256SUMS.txt`. Для большинства ARM64-телефонов выбирай
`app-arm64-v8a-debug.apk`; для старых 32-битных ARM — `app-armeabi-v7a-debug.apk`.
Android 8.0+ (minSdk 26). Поддержка конкретной модели смартфона пока не
подтверждена ручным тестом.

На телефоне можно открыть APK через файловый менеджер и разрешить установку
из выбранного источника. Через ADB на компьютере:

```sh
adb shell getprop ro.product.cpu.abilist
adb install -r app-arm64-v8a-debug.apk
```

После установки открой приложение, включи IME через настройки, выбери её
и проверь обычный набор, исправление `севодня → сегодня` после пробела
и отмену немедленным Backspace. Проверь отдельно парольное и адресное поля:
их содержимое не должно автокорректироваться. Вернись к исходной клавиатуре
в настройках, если приложение ведёт себя нестабильно.

**Важно:** это тестово подписанная сборка-кандидат, а не production release.
Отладочный ключ CI не должен использоваться для официального обновляемого
приложения. Обновление APK из разных CI-запусков может потребовать удаления
старой debug-сборки из-за различающихся ключей подписи.
Настоящий `v1.0.0` потребует защищённого релизного ключа, теста установки
и обновления на смартфоне и отдельного согласия на публикацию.

## Большой словарь и план качества

Скрипт `scripts/build_russian_typos.py` и workflow `lexicon-stress` используют
лицензированные русские словари. Цель — 100 000 настоящих разных словоформ
и не менее миллиона уникальных **искусственных** опечаток с имитацией соседних
клавиш, пропусков, повторов и перестановок. Метрики и источники описаны в
`docs/RUSSIAN_LEXICON_QA_RU.md`. В rc2 корпус скомпилирован в индекс APK.
Автоматические замены ограничены отдельно. Чужой ввод и личные переписки
не используются.
В rc3 обнаруженные настоящие словоформы из этой таблицы блокируются
морфологическим словарём и остаются неизменными. Общий поиск не ограничен
этой таблицей.

В новом экране запуска текст сокращён, тестовое поле расширено, добавлен
отступ нижнего ряда клавиатуры от системной навигации и доступ к букве `ё`.
