# RussianKeyboard Android — ранний MVP

Это **настоящая Android IME**, добавленная в тот же репозиторий, что и Python Trainer.
Пока без AI-весов: словарь из 10 безопасных замен и ограниченные демонстрационные правила запятых.

## Сборка

JDK 17, Android SDK 35, Gradle 8.9.

GitHub проверяет через три workflow: `validate` (в том числе FP32/INT8 ONNX), `android-build` (unit/lint/APK) и `android-emulator` (API 35, 3 ГБ RAM). См. `docs/GITHUB_TEST_MATRIX_RU.md`.

В приложение не встроен ONNX inference; тест экспортированной модели выполняется только на сервере CI.

```sh
gradle -p android --no-daemon testDebugUnitTest assembleDebug
```

После успешного GitHub Actions `android-build` debug APK доступен в Artifacts.
Путь сборки: `android/app/build/outputs/apk/debug/app-debug.apk`.

## Использование

Установи APK, открой приложение и нажми «Включить клавиатуру», затем «Выбрать клавиатуру».
Для тестов используй обычное поле ввода. Клавиатура распознаёт нажатия букв, Backspace,
пробел, запятую, точку и Enter. При пробеле пробует локальное исправление.

## Важно

- Нет INTERNET-разрешения, нет отправки текста и аналитики.
- В парольных и других чувствительных полях корректировки не запускаются.
- Исправления букв и пунктуации пока детерминированные, не обученная нейросеть.
- Не реализованы автопредсказание координат, история коррекции/Undo, полноценный
  словарь, разрешение местоимений, адаптация к собеседнику, работа с клавиатурами
  всех языков, модель ONNX и пунктуация RUPunct.
- Требуются отдельные тесты на 3–4 GB RAM, PSS, jank, температуру и battery.
- Не использовать прототип как основную клавиатуру для важных сообщений.
