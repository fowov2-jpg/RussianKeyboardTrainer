# Политика данных

1. Файлы `data/eval/SAGE95M_*` — только локальный внешний regression/evaluation baseline. В public GitHub их не коммитить; не использовать в train или tuning thresholds.
2. Train должен строиться из отдельно лицензированных чистых корпусов и/или открытых error-pair корпусов с сохранением лицензий.
3. Личные пользовательские сообщения не загружать в GitHub и не использовать для обучения без отдельного явного opt-in и механизма удаления/анонимизации.
4. Split делается по `group_id`, чтобы кандидаты одного исходного слова никогда не попадали в разные train/val/test.
5. Safety/KEEP выборка должна быть независимой от train.
