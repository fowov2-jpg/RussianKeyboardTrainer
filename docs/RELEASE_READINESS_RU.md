## Финальная версия (кандидат, НЕ выпущена)

- [ ] Независимый лицензированный русский корпус с разделением train/validation/test до синтеза; исключить утечки.
- [ ] Измерить FCR на **чистых KEEP** и точность/recall исправлений на реальных опечатках, включая домены, имена, смешанный регистр, сленг. Порог FCR ≤ 0,5% пока **цель**, не подтверждённая оценка на независимом корпусе.
- [ ] Только после такой оценки решать о подключении реальных обученных ONNX-весов; синтетическая модель из CI не является продуктовой.

- [ ] UX/accessibility, локализация, поведение IME в популярных приложениях, длинные сессии и crash-free регрессия.
- [ ] Security/privacy review, матрица поддерживаемых Android/ABI, changelog, release signing и согласие владельца на публикацию.

## Принцип безопасного продвижения

1. Любое изменение — в feature-ветке, с тестами и повторным зелёным CI на актуальном SHA.
2. Не подменять эмулятор физическим устройством и synthetic ONNX реальной обученной моделью.
3. Не менять `main`, не сливать PR, не публиковать release/tag без отдельного согласия владельца.
4. Если чеклист не закрыт, статус **pre-release / MVP**, а не «стабильная» или «финальная».
