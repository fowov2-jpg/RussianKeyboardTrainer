# Отдельная версия без чтения чата — rc9-local

Полная rc8 была заблокирована Play Защитой при установке из файла.
Предупреждение на скриншоте подтверждает блокировку, но его полный текст
закрыт диалогом установщика. Точная причина пока не установлена.
Возможный фактор — сервис Accessibility, который в полной версии читает
видимый разговор после отдельного включения пользователем.

Подготовлен дополнительный вариант `standalone`, версия `1.0.0-rc9-local`,
versionCode=10. Исправление текста, который пользователь набирает,
офлайн-пунктуация, подсказки, отмена и ручной контекст остаются доступны.
Сервис чтения экрана удалён из итогового AndroidManifest. В настройках
нет переключателя чтения чата или перехода к включению этого сервиса;
даже сохранённое ранее `screen_context=true` не активирует чтение.
Полная версия с отдельно включаемым доступом к чату сохранена.

Standalone не получает новые разрешения, не является debuggable и использует
тот же локальный тестовый сертификат для обновления ранее выданных APK.
Это не сертификат Google Play. Одобрение Play Защиты не проверено:
отсутствие Accessibility не гарантирует, что телефон разрешит установку.

## Проверка

```sh
gradle -p android --no-daemon --max-workers=2 testDebugUnitTest lintDebug lintStandalone assembleDebug assembleStandalone assembleDebugAndroidTest
python scripts/ci_verify_android_lexicon.py
python scripts/ci_verify_android_lexicon.py --apks android/app/build/outputs/apk/standalone
python scripts/ci_verify_standalone_apk.py
```

Последняя команда проверяет фактические APK трёх ABI: отсутствие сервиса
Accessibility и его BIND_ACCESSIBILITY_SERVICE/intent filter, наличие
клавиатурного сервиса, выключенный ресурс доступа к чату, отсутствие
запрашиваемых разрешений, non-debuggable, подпись и zipalign. Проверка
словарей подтверждает сохранение модели, индексов, хешей, mmap и лицензий.
Результат — `android/app/build/reports/standalone-apk.json`.

Проверки исходного кода и упаковки не заменяют установку на физический
телефон. Отдельный вариант позволяет проверить установку с меньшим набором
доступа, но не объясняет автоматически причину исходной блокировки.

Локально прошли 25 610 JUnit-случаев, lint обеих версий, сборка всех трёх
ABI обеих версий, компиляция Android-тестов и обе проверки упакованных
индексов. Аудит standalone-APK подтвердил перечисленные ограничения
на всех трёх ABI. Последующая правка пояснения в панели контекста также
скомпилирована с повторным lint и сборкой обеих версий. Установка на POCO
и одобрение Play Защиты остаются непроверенными.

## Установка

Для современного POCO предназначен ARM64. Скачайте ZIP, распакуйте его
в «Файлах» и откройте APK. В названии приложения указано «без чтения чата».
При блокировке Play Защитой нужен полный текст предупреждения; отключать
защиту для этого диагностического шага не требуется.

При переходе между локальными сборками с тем же сертификатом настройки
сохраняются. APK из GitHub Actions могут иметь другой тестовый сертификат;
несовместимость подписи является отдельной причиной отказа установщика.
