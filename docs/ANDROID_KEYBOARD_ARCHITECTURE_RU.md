# Android keyboard integration: безопасный быстрый ввод

Этот репозиторий **обучает Context Ranker**, но **не содержит готового Android IME**.
Сборка APK, замеры на реальном Android и качество пунктуации здесь пока НЕ подтверждены.
Никакие веса RUPunct, ruBERT или SAGE автоматически не скачиваются.

## Назначение компонентов

1. UI/IME: Kotlin InputMethodService и InputConnection; ни одна модель не блокирует UI.
2. После пробела: локальный словарь + spatial decoder формируют кандидатов, включая KEEP.
3. Context Ranker оценивает кандидатов **одним батчем**, а не генерирует новое предложение.
4. Проверка пунктуации: отдельная ONNX-модель, запуск асинхронно и с отменой устаревших задач; модель ещё не интегрирована.
5. Грамматические изменения рода, местоимений и смысла: только после отдельной оценки и при высокой уверенности; не считать род собеседника известным по «она» в текущем тексте.

## Обязательные гарантии до замены слова

- У кандидатов есть KEEP с точным исходным словом.
- Best non-KEEP score строго выше KEEP score + откалиброванного keep_margin.
- Версия текста на момент результата совпадает с текущей. На Android **дополнительно** проверяются курсор, редактируемый диапазон и фактический текст в InputConnection.
- Поля паролей и иные чувствительные поля не обрабатываются моделью.
- Грамматические переформулировки запрещены в быстром автокорректоре по умолчанию.
- Результаты пустых/невалидных оценок не применяются. После любого исправления пользователь может сделать Undo.

Эталонный Python-контракт для логики выбора: src/rsk_trainer/correction_policy.py.
Это спецификация и проверяемая политика, **не Android SDK-компонент**.

## Ограничения устройств с 3–4 ГБ RAM

- Не держать три нейросети в памяти без измерений. Одна очередь inference.
- Отложенный анализ пунктуации только после пробела, debounce и coalescing.
- Кэшировать короткий контекст, не пересчитывать всю историю.
- На Android измерить P50/P95 задержек, PSS памяти, потребление батареи, нагрев и false correction rate на независимом русском тестовом наборе.
- Не отправлять ввод пользователя на сервер и не сохранять личные сообщения в публичный репозиторий.
