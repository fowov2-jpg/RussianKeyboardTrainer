# Предварительные заметки к выпуску (НЕ опубликовано)

Дата подготовки: 2026-11-04. Статус: **1.0.0-rc3 / тестовая локальная сборка**, не официальный v1.0.0.

## Изменения rc3

- Контекстное ранжирование, общий поиск невиденных ранее опечаток,
  продолжение слова и следующее слово.
- «Проверить фразу»: просмотр, применение, отмена и Undo всей замены.
- Согласование прошедшего времени с явным «он/она/оно»; неизвестный род
  автора и адресата не угадывается.
- Компактная защита известных словоформ OpenCorpora: 11 319 строк
  синтетического корпуса теперь выполняют KEEP, а не замену по таблице.
- Одна отменяемая очередь анализа, защита от результатов для старого курсора.
- EN, цифры/символы, настройки, Unicode Backspace и действия Enter.
- Данные, лицензии, проверки и реальные ограничения описаны в
  [CONTEXT_KEYBOARD_RC3_RU.md](CONTEXT_KEYBOARD_RC3_RU.md).

## Изменения rc2

- Офлайн-индекс 100 000 словоформ и 1 000 000 разных синтетических опечаток.
- Подсказки над клавишами, явный выбор варианта и «Оставить».
- Частотные одиночные опечатки исправляются по пробелу; выявленные
  неоднозначности, редкие формы и две ошибки остаются ручными вариантами.
- Backspace отменяет замену; следующий пробел сохраняет отменённое слово.
- Словарь загружается фоном через mmap без миллиона объектов в куче.
- Локально пройдены проверка всех миллиона пар настоящим Kotlin-движком,
  Android unit/lint, сборка трёх debug APK, компиляция instrumentation,
  аудит упаковки/лицензий/подписей/отсутствия запрошенных permissions.
- Новые instrumentation-сценарии и установка на телефон ещё не выполнены;
  текущие изменения не отправлены в GitHub.

## Подтверждено на debug APK

- Android IME с русской раскладкой, локальным набором текста, Shift, Backspace, пробелом, запятой, точкой и Enter.
- Детерминированный словарь из 10 распространённых опечаток, ограниченные демонстрационные запятые, одноразовая отмена исправления Backspace.
- Защита структурированных и чувствительных полей; запрет исправления фрагментов URL, идентификаторов, упоминаний и стилизованного смешанного регистра.
- Отсутствие запрошенных разрешений в упакованных debug APK проверяется через `aapt dump permissions`; в том числе нет INTERNET.
- Отдельные debug APK для arm64-v8a, armeabi-v7a и x86_64; тесты на Android API 35 и эмуляторе 3 ГБ RAM.
- Четыре workflow успешно завершились на `fafd1b4`. Ссылки: [validate](https://github.com/fowov2-jpg/RussianKeyboardTrainer/actions/runs/41727552001), [android-build](https://github.com/fowov2-jpg/RussianKeyboardTrainer/actions/runs/41727551841), [android-emulator](https://github.com/fowov2-jpg/RussianKeyboardTrainer/actions/runs/41727551900), [android-onnx-smoke](https://github.com/fowov2-jpg/RussianKeyboardTrainer/actions/runs/41727551970).

## Не входит в текущий MVP

- Универсальная автокоррекция, предсказание слов, персонализация и продуктовые нейросетевые веса. ONNX smoke использует синтетическую модель исключительно для технической проверки.
- Проверенные показатели FCR, качества исправлений, батареи, P95 latency и памяти на реальных телефонах.
- Подписанный production APK, проверенный сценарий обновления, формальная политика поддержки и опубликованный релиз. Текущие APK подписаны только для отладки CI; внешняя проверка физического устройства всё ещё нужна.

## Кандидат к тестированию на смартфоне

- На версии `1.0.0-rc1` (`versionCode=2`) CI должен исполнить не менее 10 000 отдельных JUnit-кейсов с русскими словами, предложениями, KEEP и корректировками. Они получаются из 585 проверочных строк, расширенных 17 контекстами (10 530 разных входных строк, но не 10 530 уникальных слов). Это регрессия ограниченного движка, а не внешняя оценка точности русского языка.
- Артефакт `russian-keyboard-debug-apk` включает SHA-256 контрольные суммы; скачивание из GitHub Actions. Проверка завершённого CI по HEAD обязательна.
