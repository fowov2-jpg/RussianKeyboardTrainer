# Контекстная клавиатура rc3

Направление взято из `ANDROID_KEYBOARD_ARCHITECTURE_RU.md`,
`INTEGRATION_1.8.0_RU.md` и задач GitHub #3–#5: офлайн-кандидаты,
контекст, одна фоновая очередь, сохранение исходного текста при
неуверенности, просмотр языковых изменений и Undo. Данные переписки
и история других приложений для обучения не используются.

## Что реализовано

- Общий поиск по словарю с расстоянием Дамерау — Левенштейна до двух
  правок. Поддерживаются новые сочетания пропусков, вставок, замен и
  перестановок, которых нет в таблице миллиона синтетических ошибок.
  Поиск ограничен 30 тысячами посещённых узлов, работает в фоне.
- Контекстное ранжирование вариантов по статистической модели 1–3-грамм,
  обученной на фиксированной выборке 150 тысяч предложений Tatoeba.
  Части train/validation/test разделяются по лексическому хешу предложения
  **до обучения**. Варианты регистра, пробелов и пунктуации одной фразы
  остаются в одной части. Для выборки и split используются разные половины хеша.
- Защита известных словоформ OpenCorpora через неизменённый компактный
  DAWG-словарь (~7 МБ, 5 140 211 записей). Не требуется создавать миллионы
  строк в памяти. Учитываются обычные варианты написания е/ё.
- До трёх подсказок, продолжение слова и следующее слово; любой новый
  контекстный вариант применяется только по нажатию. Базовая ограниченная
  автозамена по пробелу сохранена с новой морфологической защитой.
- «Проверить фразу» анализирует последние 240 символов. Просмотр результата
  занимает место буквенных рядов, не увеличивая высоту клавиатуры. Только
  «Применить» заменяет текст; «Отмена» ничего не меняет. Backspace отменяет
  всю замену фразы одним действием.
- Простое согласование прошедшего времени с явно указанным «он/она/оно».
  Формы выводятся из морфологического словаря и UD; существительные и
  причастия не превращаются в личные формы глагола. Проверяются также до
  двух промежуточных слов из ограниченного списка, например «она мне очень
  понравился → она мне очень понравилась». Род «я/ты» и адресата не угадывается.
- Просмотр ограниченных правил запятой; точка из-за паузы не вставляется.
  Регистр, упоминания, URL, пароли и обычные имена внутри фразы защищены.
- Настройки автозамены и подсказок, русская/английская раскладки,
  цифры/символы, действие Enter по типу поля, Backspace по кодовым точкам.

## Потоки и редактор

`LatestRequestQueue` имеет один поток и не больше одной ожидающей задачи.
Новый ввод отменяет старую работу; уже отправленный в UI callback тоже
проверяет ревизию. Подсказки запрашиваются после 60 мс без нового нажатия.
Поток нажатий не выполняет поиск по trie или анализ фразы.

Перед применением проверяются поле, выделение, текст до курсора, положение
курсора и сессия ввода. Переключение редактора, перемещение курсора,
закрытие клавиатуры или уничтожение службы отменяет ожидающие предложения.
Правила не читают контекст чувствительных полей. В SharedPreferences
сохраняются только два переключателя; введённый текст не записывается.

Все `.bin` хранятся в APK без сжатия и отображаются только для чтения через
`FileChannel.map`. Основной словарь, trie, контекстные вероятности и DAWG
открываются в фоновом потоке. Пока морфологический словарь не открыт,
большая таблица не используется для автоматической замены.

## Источники и воспроизведение

Tatoeba: CC BY 2.0 FR; список авторов — `context/Tatoeba-AUTHORS.txt`.
OpenCorpora/pymorphy3-dicts-ru: данные CC BY-SA 3.0; неизменённый DAWG
с атрибуцией. UD Russian GSD: CC BY-SA 4.0. Адаптированная таблица
грамматических форм распространяется под CC BY-SA 4.0. Считыватель DAWG
основан на DAWG-Python, MIT; текст лицензии включён.
Точные URL, версии и SHA-256 — в `assets/context/manifest.json`.

Для обычной сборки уже включены готовые assets и тестовые fixtures.
Для воспроизведения статистической модели:

```sh
python -m pip install --target .cache/morphology \
  pymorphy3==2.0.6 pymorphy3-dicts-ru==2.4.417150.4580142 dawg2-python==0.9.0
python scripts/build_russian_typos.py --out reports/lexicon
python scripts/build_context_assets.py --download --detailed \
  --words reports/lexicon/words-100000.txt
gradle -p android testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
python scripts/ci_verify_android_lexicon.py
```

Экспорт Tatoeba меняется; генератор принимает только зафиксированный
SHA-256, а не незаметно переобучается на другой версии данных.

## Проверка и границы

Проверяются все миллион исходных пар через Kotlin-поиск и движок. Часть
«синтетических ошибок» оказалась настоящими словоформами по более полному
словарю: они остаются неизменными (KEEP), а не исправляются по таблице.
Их число явно записано как `morphology_keep` в отчёте.

Отдельные проверки: соответствие DAWG-считывателя Python на более чем
10 тысячах положительных/отрицательных примеров, новые сочетания ошибок,
многословные изменения, согласование, защищённый текст и отмена устаревших
фоновых результатов. Holdout-отчёт содержит число предложений/слов,
автоматические изменения чистого источника и попадание цели в top-3 для
160 новых синтетических ошибок. Это не точность на настоящих ошибках людей.
Времена в этом отчёте относятся к JVM хосту, не к телефону.

Это **статистический** ранжировщик и ограниченные морфологические правила.
RUPunct/ruBERT и продуктовые ONNX-веса не выданы за готовую нейросеть.
Нет полного исправления произвольной грамматики, понимания адресата или
гарантии восстановления слова с любым количеством ошибок. Проверки
физических устройств, батареи, PSS и задержки набора остаются отдельными.
