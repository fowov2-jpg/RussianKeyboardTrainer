# Нижний ряд и регистр — rc10

Версия 1.0.0-rc10, versionCode=11. Полная клавиатура с отдельно включаемым
контекстом видимого чата сохранена. Дополнительный standalone-вариант также
сохранён; уже решённая пользователем установка не требует перехода на него.

## Кнопки над системной навигацией

Фиксированный нижний отступ 30 dp заменён обработкой WindowInsets.
IME-окно самостоятельно учитывает видимые navigationBars и область
mandatorySystemGestures. Нижняя, левая и правая границы клавиш отступают
от соответствующей системной полосы; под нижним рядом остаётся 8 dp
дополнительного места. До первого события используется системный размер
navigation_bar_height. Смена режима навигации вызывает пересчёт отступа.
Для Android 26–29 используется совместимый путь systemWindowInsets.

Режим навигации пользователя приложение не меняет. В Android-тестовом
эмуляторе явно включается трёхкнопочная навигация, чтобы воспроизводить
перекрытие нижнего ряда. Тест проверяет не обрезанные accessibility-границы,
а фактические координаты View. Затем нажимает «ё», запятую, пробел, точку
и Enter в трёх пикселях от нижнего края и проверяет введённые символы.
Диагностика RSK_IME_GEOMETRY содержит только геометрию синтетического теста.

## Заглавные внутри предложения

Добавлен словарный ограничитель автоматического регистра для 14 412
обычных глагольных форм и наречий из закреплённого списка FrequencyWords
и OpenCorpora. Например, предсказание модели не превращает внутреннее
«поднять» в «Поднять». После настоящей границы предложения заглавная
по-прежнему допустима. Уже введённые пользователем заглавные не понижаются.

Критерий не выбирался по ответам QA: **все** словарные разборы слова должны
быть известными VERB/INFN/ADVB/GRND и не содержать признаков имени,
географического названия, организации или аббревиатуры. Неоднозначные
слова не добавляются. Имена и названия городов сохраняют прежнюю политику.
Предпросмотр REVIEW остаётся отдельным режимом с прежними предложениями.
Это ограничитель словарных классов, а не обучение весов нейросети.

Генератор: `scripts/build_punctuation_case_guard.py`. При полной генерации
частотного индекса он вызывается автоматически. Файл и хеши находятся
в `assets/common/punctuation_lowercase.txt` и `common/manifest.json`.
Производные данные — CC BY-SA 3.0; исходный список, морфологическая
версия и хеши файлов словаря закреплены. Частные сообщения не используются.

## Проверки

Локально прошли 25 611 JUnit-случаев, lint, сборка трёх ABI и компиляция
Android-тестов. Три дополнительных авторских контрольных предложения
проверены с настоящими закреплёнными логитами; ошибочно уверенная модельная
заглавная также проверена отдельно. Ни исходные 7 500 + 7 500 QA-входов,
ни их эталоны не менялись. Таблицы результатов совпадают с rc9: 746 / 1000
и 922 / 1500 полных восстановлений, 988 / 1000 и 1466 / 1500 готовых фраз
сохранены, структурных нарушений нет. Это регрессия, а не доказательство
улучшения средней точности на переписках пользователей.

Новый Android-тест реальных нижних касаний должен выполняться отдельно
в GitHub Actions; его компиляция не заменяет выполнение. Проверка на
конкретном телефоне необходима для подтверждения поведения OEM-навигации.

Воспроизведение:

```sh
PYTHONPATH=.cache/morphology python scripts/build_punctuation_case_guard.py
PYTHONPATH=.cache/punctuation-python python scripts/prepare_punctuation_reference.py
gradle -p android --no-daemon --max-workers=2 testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
python scripts/ci_verify_android_lexicon.py
```

Старые границы: синтетические опечатки измеряют покрытие индекса;
OpenSubtitles не является статистикой мессенджеров; пересечение Tatoeba
с обучением RUPunct неизвестно. Физический телефон не сертифицирован.
