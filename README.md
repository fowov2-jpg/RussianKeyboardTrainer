Вход в GitHub не требуется. Скачайте ZIP, распакуйте его в приложении «Файлы» и откройте APK внутри папки. Разрешите установку из выбранного приложения. После установки откройте клавиатуру, включите и выберите её.

Версия 1.0.0-rc8, versionCode=9, исходный коммит 6e56bcb. Это локально собранные и проверенные APK; их подпись совместима с ранее выданными локальными rc3–rc7. APK из GitHub Actions могут иметь другую тестовую подпись.

Локально прошли 25610 JUnit-случаев, lint, сборка трёх ABI, компиляция Android-тестов, проверка подписи, выравнивания и упакованных активов. Выполнение новых Android-тестов проверяется отдельно в Actions; это кандидат для проверки на реальном телефоне. Клавиатура ещё допускает ошибки. Интернет не запрашивается.
