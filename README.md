# Русская клавиатура rc10 — полный вариант для ARM64

[Скачать ZIP с APK без входа в GitHub](https://raw.githubusercontent.com/fowov2-jpg/RussianKeyboardTrainer/apk-rc10/RussianKeyboard-1.0.0-rc10-ARM64.zip)

Распакуйте архив в «Файлах» и откройте APK. Версия 1.0.0-rc10, versionCode=11.
Подпись совпадает с ранее выданной локальной rc8: можно обновить её с сохранением настроек.

Нижний ряд учитывает реальную область системной навигации вместо фиксированного отступа. Добавлена словарная защита от лишних заглавных для обычных глаголов и наречий внутри предложения. Контекст видимого чата и остальные функции полной версии сохранены. Веса нейросети не переобучались, языковые ошибки ещё возможны.

Локально прошли 25611 JUnit-случаев, lint, сборка трёх ABI, компиляция Android-тестов, проверка подписей, zipalign и упакованных активов. Результаты прежних двух наборов по 7500 входов сохранены. Новый тест фактических нижних касаний с трёхкнопочной навигацией прошёл на Android 15 / 3 ГБ. Все пять проверок GitHub исходного коммита прошли; подробности в CI_VERIFICATION.json. На конкретном POCO обновление ещё нужно проверить.

ZIP содержит полный APK с отдельно включаемым сервисом видимого контекста. Установка и одобрение Play Защиты на телефоне зависят от Android. Приложение не запрашивает INTERNET; чат не записывается на диск.
