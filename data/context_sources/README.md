# Context sources

`tatoeba-rus-cc0-20261031.tsv.bz2` is the unchanged Russian CC0 export from
Tatoeba, 2026-10-31. License: CC0 1.0. SHA-256:
`3b6645bbc18e4e3444ebc9195c4a6c41ff521a8bc4306fec8fcc217ae734db76`.
Source: https://downloads.tatoeba.org/exports/per_language/rus/rus_sentences_CC0.tsv.bz2

The shipped rc3 model uses a larger attributed sample of the detailed Russian
export (CC BY 2.0 FR). Exact snapshot hash, corpus URLs and licenses are in
`android/app/src/main/assets/context/manifest.json`. All credited contributors
are listed in `Tatoeba-AUTHORS.txt`; original sentence IDs are retained in the
heldout fixture. No private messages are used.

Original sources:
- Tatoeba: https://tatoeba.org/en/downloads
- CC BY 2.0 FR: https://creativecommons.org/licenses/by/2.0/fr/
- OpenCorpora: https://opencorpora.org/ (CC BY-SA 3.0).

  (CC BY-SA 4.0; pinned commit in the manifest).
